# 金晶怡 Jingyi — Portfolio

中央美术学院产品设计个人作品集（2023—2026）。采用原生 HTML、CSS、JavaScript，无第三方运行时依赖。

## 运行

需要 Node.js 18+。在仓库目录运行：

```sh
npm run dev
```

默认端口为 3000，可使用 PORT 环境变量覆盖。`npm run check` 检查脚本语法。

## 作品内容

真实内容来自用户提供的《作品集-中央美术学院-金晶怡.pdf》，并非 Figma 在线抓取。网站包含：

1. 菌伞拾光：儿童互动音乐玩具。
2. 移动生活空间：汽车座舱与 CMF 概念。
3. 再现立方：视错觉与木作座椅。
4. 未结椅：情绪概念坐具。
5. 云栖木：木材与不锈钢茶具。
6. 半间 HEMI：家居品牌视觉系统。
7. 雾岸：福建沿海摄影与摄影书设计。

`app.js` 保存项目介绍、分类和对应 PDF 页码。`assets/portfolio/` 包含 7 张封面及 36 张项目展示页，已转为 JPEG，详情页懒加载图片。PDF 的简历、生日与电话不在页面资源中，联系区使用作品集内的邮箱。没有公开原始 PDF。

`index.html` 保存个人介绍和联系信息；`style.css` 定义响应式布局；`server.mjs` 用于本地开发。可直接部署静态文件，不需要构建步骤。参考方向为用户上传的截图及 Interlude 的简洁排版与转场。
